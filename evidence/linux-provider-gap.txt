# Linux 桌面 Provider 配置（2026-11-09，deb GUI 实测）

首启 Add API Key 页只有官方 key，没有 Base URL/模型字段 —— 这是 onboarding 的
UX 缺口，不是能力缺失。

跳过首启后：More → Settings → Models → Add model provider → Custom model API，
可以看到 Provider ID / Display name / Base URL / API key / models 等字段，说明
Linux 桌面具备自定义 OpenAI 兼容供应商的能力。
