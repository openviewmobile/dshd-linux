# Support

## Where to ask

- **Usage questions, ideas, screenshots:** use
  [GitHub Discussions](https://github.com/openviewmobile/dshd-linux/discussions).
- **Reproducible bugs:** open a
  [bug report](https://github.com/openviewmobile/dshd-linux/issues/new?template=bug_report.yml)
  with the required version, distribution, architecture, and logs.
- **Feature requests:** use the
  [feature request form](https://github.com/openviewmobile/dshd-linux/issues/new?template=feature_request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md) and use a private
  advisory. Never paste keys, tokens, or private workspace data in a public
  issue.

## Before opening an issue

1. Check the [README](README.md) support table and the
   [documentation index](docs/README.md).
2. Try the latest Release and confirm your architecture with `uname -m`.
3. For package-manager issues, include the exact command and whether you used
   the Release asset or the APT/DNF repository.
4. For UI/Office issues, state whether the problem happens with a fresh profile
   and whether a third-party plugin is enabled.

## Support scope

Supported: Debian/Ubuntu `.deb`, Fedora/RHEL/Rocky `.rpm`, AppImage, Flatpak, and
the x86_64 APT/DNF repositories. aarch64 is supported through Release assets.
Arch/AUR, openSUSE OBS, Nix, Gentoo, and Snap are community/packaging recipes
with the verification status documented in the README.

No response-time SLA is promised. The project is maintained in spare time; a
clear, reproducible report is the fastest path to a fix.

## Supported versions

See [SECURITY.md](SECURITY.md#supported-versions). Release candidates are
supported only until the next release candidate or stable release.
