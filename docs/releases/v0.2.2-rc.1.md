# DSHD for Linux 0.2.2-rc.1

First public release candidate of the Linux desktop distribution. It packages
the upstream DeepSeek Harness desktop runtime for Linux x86_64 and aarch64,
with AppImage, deb, rpm, Flatpak and distro-specific packaging.

> This is a release candidate. Keep backups and expect rough edges on Wayland,
> Snap, and distribution-specific desktop integration.

## Install

```bash
# AppImage (checksum + signature first)
gpg --import keys/deepseek-harness-release-signing.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS
chmod +x deepseek-harness-0.2.2-rc.1-linux-x86_64-unsigned.AppImage
./deepseek-harness-0.2.2-rc.1-linux-x86_64-unsigned.AppImage

# deb / rpm
sudo apt install ./deepseek-harness-0.2.2-rc.1-linux-amd64-unsigned.deb
sudo dnf install ./deepseek-harness-0.2.2-rc.1-linux-x86_64-unsigned.rpm

# Flatpak (bundle; runtime 25.08 must be installed)
flatpak install --user --bundle deepseek-harness-0.2.2-rc.1-linux-x86_64-unsigned.flatpak
flatpak run com.deepseek.harness

# Arch
sudo pacman -U deepseek-harness-bin-0.2.2_rc.1-1-x86_64.pkg.tar.zst
```

Flatpak requires the freedesktop 25.08 runtime and the Electron2 BaseApp:

```bash
flatpak install flathub org.freedesktop.Platform//25.08 \
  org.freedesktop.Sdk//25.08 org.electronjs.Electron2.BaseApp//25.08
```

## Highlights

- Flatpak on `org.freedesktop.Platform//25.08` for x64 and arm64, with a
  launcher that fixes the empty `PATH`/`electron-wrapper` failure.
- Real-provider end-to-end chat test (no mocks).
- PDF/Office export via the bundled LibreOfficeKit WASM backend, including
  DOCX/PPTX/XLSX and legacy DOC/XLS/PPT, with rendered-page evidence.
- Arch/AUR package built, installed with `pacman -Udd`, and launched under Xvfb.
- Snap and OBS packages built locally (see limitations).
- Detached GPG signatures and a published release key.

## Known limitations

- Filenames keep the historical `unsigned` suffix; these are GPG detached
  signatures, not platform code-signing certificates.
- Snap was assembled with squashfs, not `snapcraft`, and was not installed
  with `snap install`; strict confinement is unverified.
- OBS was built with a local `rpmbuild`, not on the OBS service.
- Nix and Gentoo packaging files are provided but were not built in the
  reference environment.
- Wayland-native sessions, tray icons and IME behavior are not verified on
  physical desktops.
- The release key has no passphrase in this reference environment; replace it
  with an offline protected key before a production release. See
  [release-signing.md](../release-signing.md).
