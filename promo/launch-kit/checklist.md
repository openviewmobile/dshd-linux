# Launch checklist

## Before posting

- [ ] Release `v0.2.2-rc.1.3` is public and assets download.
- [ ] README links point at that release.
- [ ] APT/DNF install smoke is green.
- [ ] GPG, SBOM and provenance verification commands work.
- [ ] GitHub social preview and topics are set.
- [ ] Chinese and English copy both clearly say “not official”.
- [ ] No claim of full Wayland/KDE/GNOME validation.
- [ ] One person is available to answer comments for 4–6 hours.

## Posting order

1. GitHub Release + Discussion
2. DeepSeek/DSH community / awesome list
3. Hacker News Show HN
4. r/LocalLLaMA
5. r/linux / r/selfhosted / Lobsters
6. V2EX
7. 掘金 / 知乎
8. YouTube walkthrough

## After posting

- [ ] Reply to every reproducible issue within 24 hours.
- [ ] Label issues by distro and format.
- [ ] Publish a short “what broke on launch day” follow-up.
- [ ] Do not argue with negative feedback; ask for logs.
- [ ] Record downloads, installs and top failure modes.
