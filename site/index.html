DSHD · DeepSeek Harness Desktop

Linux packages

APT and DNF repositories for the x86_64 release, generated from the signed GitHub Release by GitHub Actions.

Debian / Ubuntu (APT)

curl -fsSL https://openviewmobile.github.io/dshd-linux/key.asc | sudo gpg --dearmor -o /usr/share/keyrings/dshd-linux.gpg
echo "deb [signed-by=/usr/share/keyrings/dshd-linux.gpg] https://openviewmobile.github.io/dshd-linux/apt stable main" | sudo tee /etc/apt/sources.list.d/dshd-linux.list
sudo apt update
sudo apt install deepseek-harness

Fedora / RHEL / Rocky Linux (DNF)

sudo curl -fsSL https://openviewmobile.github.io/dshd-linux/dshd-linux.repo -o /etc/yum.repos.d/dshd-linux.repo
sudo dnf install deepseek-harness

Other distributions

AppImage, Flatpak, aarch64 packages and source recipes are on the GitHub Release. Arch/AUR and other recipes are in the repository under packaging/.
